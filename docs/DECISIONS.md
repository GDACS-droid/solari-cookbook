# Decisions

| Date | Decision | Basis | Consequence |
| --- | --- | --- | --- |
| 2026-09-01 | Product name: AcreBrief | A brief is the acquisition-team output; avoids “scraper” framing | Use property/public-record positioning everywhere |
| 2026-09-01 | Lee County is the first complete slice | strongest observed clerk, court, appraiser and sale entry points | Charlotte/Collier remain registry candidates until validated |
| 2026-09-01 | Event graph, not static lead list | customer question is “what changed?” | snapshots/diffs/idempotency are core acceptance criteria |
| 2026-09-01 | Bulk/API before Browser; Desktop exceptional | lawful, stable, lower-cost retrieval is preferable | Browser/desktop adapters need source gates |
| 2026-09-01 | Solari recording is disabled in the current AcreBrief path | replay is compelling but provider retention/deletion and application review/redaction controls are not implemented | use the verified application walkthrough; do not create provider-side source recordings yet |
| 2026-09-01 | No Lee map/aerial redistribution | Lee PA policy restricts commercial redistribution | link to source facts; omit aerial/map panels and imagery |
| 2026-09-01 | Verified sample is explicit | reviewers need reproducibility without credentials | never make sample look like a live source run |
| 2026-09-01 | No contact/outreach automation | property intelligence has a legitimate narrow wedge | safer demo and clearer product boundary |
| 2026-09-01 | Business Observer live automation remains disabled | `/news/` is not robots-disallowed, but no affirmative automation terms or rate grant was found | retain the exact notices only as reviewed fixture evidence; a Solari key or environment ID cannot override the registry gate |
| 2026-09-01 | Replace the critical publisher path with Florida DOR + Cape Coral Open Data | DOR affirmatively publishes current rolls; the City expressly operates an Open Data service with parcel-keyed lien rows | `PUBLIC_DOWNLOAD`/`OPEN_DATA_API` sources are LIVE_READY; Business Observer and Clerk remain gated |
| 2026-09-01 | Public demo uses 413 SW 26th Ave as a property-only record | exact City STRAP→DOR PARCEL_ID join and current 2026 preliminary state roll; no contact fields needed | public brief shows parcel/assessment/lien facts and omits owner/customer/account/mailing data |
| 2026-09-01 | Historic active lien is enrichment, not “new today” | City table's newest active source date is July 2022 | UI and demo state the source date; the next detector must provide fresh licensed event timestamps |
| 2026-09-01 | Competition public-live route is a bounded opt-in | one exact property and approved official requests demonstrate Solari materially | `ACREBRIEF_PUBLIC_LIVE_DEMO=true`, app concurrency/cooldown plus Vercel WAF 1 request/60s per IP+JA4; atomic global quota still required before broader launch |
| 2026-09-01 | Model the 2022 City row as `LIEN_STATUS_ACTIVE`, never `NEW_LIEN` | a current source status is not evidence of a new daily event without a prior snapshot diff | it can contribute a transparent status score but never a recency bonus or “new today” alert |
| 2026-09-01 | Add Cape Coral foreclosure registrations as the first source-dated event trigger | official Open Data exposes stable municipal case IDs, exact STRAPs, and row-level opened/updated timestamps; City policy links registration to mortgagee-initiated foreclosure on vacant property | emit `FORECLOSURE_REGISTRATION_OPENED`; reserve `NEW_FORECLOSURE_REGISTRATION` for a persisted prior-state diff; preserve all four clocks and exclude owner/mailing/free-text fields |
| 2026-09-01 | Keep Lee Clerk Civil Suit Case List at the purchase boundary | the $180/year layout proves new civil/foreclosure rows and filing dates, but cadence, codebook, backfill, delivery and commercial/cloud processing terms remain unconfirmed | owner must execute the Clerk request/agreement after written scope confirmation; adapter remains gated |
| 2026-09-01 | Preserve the AcreBrief visual identity and apply only precision fixes | cold baseline review found the editorial property brief credible; the largest defect was temporal language, followed by mobile table scanability | no redesign, new logo, motion library, gradients, card system, or decorative animation |
| 2026-09-01 | Code + Utility Liens are the first snapshot feeds; Permits follows in the same runner | all three official layers expose exact parcel keys and defensible source clocks; 311 does not and Inspections lacks a reliable revision clock | enable bounded privacy-projected adapters; keep 311/Inspections `REVIEW_REQUIRED` |
| 2026-09-01 | Snapshot lookback may overlap but its end watermark must advance | late official publication/correction makes zero-overlap windows lossy | stable native keys, state hashes, and transition IDs dedupe lookback rows; stale replays fail closed |
| 2026-09-01 | Payoff is watchlist state, not a citywide distress feed | source publishes no change timestamp and `currentamt`/`payoff` do not establish a lien or delinquency | query at most 50 exact parcels, omit `NAME`, and emit only calculated amount changes after baseline |
| 2026-09-01 | Use transactional Postgres for production event state and pilot intake | Vercel filesystem is ephemeral; source watermarks and intake acknowledgements require honest durable writes | Neon free tier is provisioned/migrated; daily authenticated cron and consented pilot intake are production-enabled, while local JSON remains a test/VM adapter |
| 2026-09-01 | Publish one source-backed local intelligence page before programmatic SEO | the verified Cape Coral source window is useful and auditable; unbuilt county/category pages would be thin | sitemap lists only real routes; new pages must pass the evidence/content gate in `SEO_AND_AEO.md` |
| 2026-09-01 | Withhold SoftwareApplication rich-result markup | Google requires an offer price plus a real rating/review; AcreBrief has a pilot hypothesis but no final app price or genuine review | use truthful Organization/Article/Breadcrumb markup now; revisit after commercial validation |
